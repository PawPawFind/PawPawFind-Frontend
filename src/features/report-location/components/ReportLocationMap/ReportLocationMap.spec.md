# ReportLocationMap

제보 상세의 위도·경도를 중심으로 카카오 지도를 읽기 전용으로 표시한다. 좌표에는 마커를 두고,
`radiusM`이 0보다 크면 공개 범위를 나타내는 원을 함께 표시한다.

지원 상태: SDK loading, ready, 키 없음, SDK 오류. 키가 없거나 SDK 요청이 실패하면 동일한 크기의
격자 placeholder와 위치 안내를 유지한다. 지도는 위치를 수정하지 않으며 좌표 선택 동작을 제공하지
않는다.

## 접근성

- 지도 영역은 장소명과 좌표를 포함한 접근 가능한 이름을 갖는다.
- 지도 SDK 상태 문구는 `role=status`로 알린다.
- 지도 영역의 접근 가능한 이름에 장소명과 좌표를 제공하되 화면에는 좌표 원문을 노출하지 않는다.
